# Ayush Rocket Flight Simulation

## Overview
This project focuses on high-power rocket flight simulation and stability analysis using OpenRocket.

## Features
- Flight stability analysis
- CG and CP optimization
- H220T motor configuration
- Altitude and velocity simulation
- Recovery deployment analysis

## Software Used
- OpenRocket

## Results
- Predicted apogee around 530 m
- Stability margin approximately 1.77 cal
- Successful recovery deployment simulation
